# Contributing

Thank you for helping improve showMK. Please keep contributions small and focused.

## Before submitting

- Describe the macOS version, Mac architecture, Xcode/Swift version, and exact steps to reproduce.
- Test the normal build with `./build.sh` when possible.
- For Intel/macOS 12.4 compatibility work, report the deployment target and whether you actually ran the app on an Intel Mac with macOS 12.4.
- Do not include private device addresses, personal logs, signing credentials, certificates, or secrets in issues or pull requests.
- Do not add telemetry, network access, input capture, or automatic device connection/disconnection without discussing the change first.

## Scope

The app is intentionally small and local-only. Changes should preserve its menu-bar-first workflow, selected-device binding, and minimal permissions.
